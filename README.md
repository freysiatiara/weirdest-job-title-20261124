## The title

**Professional Apologizer for Self-Driving Cars**

Somebody has to say sorry when the car cuts you off — and that somebody is a professional.

## How to run

```sh
python3 main.py
```

This writes the title (exactly 45 characters, no trailing newline) to `/output/entry.txt`. Set `ENTRY_OUTPUT` to write somewhere else instead, e.g.:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
